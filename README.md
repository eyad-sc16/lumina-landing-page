# Lumina Tech Solutions - Landing Page

A modern, responsive landing page for **Lumina Tech Solutions**, a fictional company specializing in turning fragmented enterprise data into real-time intelligence, predictive analytics, and private AI models. 

## 🚀 Features

- **Responsive Design**: Fully responsive layout that looks great on desktops, tablets, and mobile devices.
- **Modern UI/UX**: Clean aesthetics, smooth animations (fade-up effects, animated numbers), and a professional color scheme.
- **Interactive Elements**: Includes a sticky header, mobile navigation toggle, smooth scrolling, and an interactive hero section with mockups.
- **Semantic HTML5**: Built with accessibility and SEO in mind.
- **Custom CSS3**: Uses CSS variables for easy theming, Flexbox/Grid for layout, and custom animations.
- **Vanilla JavaScript**: Lightweight DOM manipulation for navigation, scroll events, and number counting animations.

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**

## 📂 Project Structure

```
.
├── index.html      # Main HTML file containing the structure
├── styles.css      # CSS file for styling and animations
├── script.js       # JavaScript file for interactivity
└── imges/          # Directory containing project images/assets
```

## 🏁 Getting Started

To view the project locally, simply follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/lumina-landing-page.git
   ```

2. **Open the project:**
   Navigate to the project directory and open `index.html` in your preferred web browser. No build steps or local servers are required!

   ```bash
   cd lumina-landing-page
   # On Windows
   start index.html
   # On macOS
   open index.html
   # On Linux
   xdg-open index.html
   ```
