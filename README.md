# Lumina Landing Page

A modern, responsive, and feature-rich enterprise SaaS landing page equipped with advanced accessibility tools, interactive UI animations, dark mode, sign language options, text-to-speech reader, and dynamic data visual effects.

## Features

- **Accessibility Toolbar**: Full-featured accessibility widget supporting large cursor, link highlighting, bold text adjustment, readable font switching (Roboto/Default), animation pausing, character spacing, dark mode toggle, text alignment, reading ruler, sign language, and text-to-speech selection reading.
- **Dynamic Theme Switcher**: Instant switching between light and dark themes with persistent visual state.
- **Interactive UI Components**: Smooth scrolling navigation, mobile responsive hamburger menu, dynamic year updates, random number generation effects on statistics, and IntersectionObserver-powered scroll animations.
- **Performance Optimized**: Lazy loading for images and structured modular JavaScript architecture.

## Technologies Used

- **HTML5** & **CSS3** (Custom Properties, Flexbox, Grid)
- **Vanilla JavaScript** (ES6+, Classes, IntersectionObserver API, SpeechSynthesis API)
- **Google Fonts** (Fraunces, Inter, JetBrains Mono, Roboto)

## Project Structure

```
├── index.html         # Main landing page markup & accessibility widget
├── styles.css         # Styling, dark theme, and accessibility utility classes
├── script.js          # Core UI interactions, navigation, and animations
├── accessability.js   # Accessibility features and DOM manipulation class
└── fonts/             # Custom local font assets
```
